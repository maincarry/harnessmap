Planning Japan in October, me and my partner, budget about 3k on the ground. Hard rule: back by the 11th, my sister's wedding. Tokyo and Kyoto only — no side trips. And no red-eye flights, I'm too old for that. First thing: figure out the rail pass vs individual tickets.
The rail pass question for a Tokyo-Kyoto trip is pretty clear-cut once you run the numbers. A 7-day JR Pass currently runs around $430-450 per person (so ~$900 for two). The Shinkansen round trip Tokyo-Kyoto is about $130 each way per person — so $520 round trip for two. That's already more than half the pass cost just for the bullet train, and you haven't counted any other JR trains. If you're doing the classic move — fly into Tokyo, spend several days, take the Shinkansen to Kyoto, spend several days, Shinkansen back — the pass usually wins, but only if you're also using JR trains within the cities…
